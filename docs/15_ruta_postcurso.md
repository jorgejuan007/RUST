# Ruta Postcurso

Si ya cerraste este repositorio, esta es una buena hoja de ruta para no quedarte en el nivel de ejemplos.

## Ruta 1. CLI y automatizacion

Aprende en este orden:

1. `clap`
2. `serde`
3. `csv`
4. `anyhow`
5. `thiserror`

Proyecto sugerido:

- gestor de tareas con exportacion

## Ruta 2. Backend

Aprende en este orden:

1. `serde`
2. `reqwest`
3. `tokio`
4. `axum`
5. `sqlx`

Proyecto sugerido:

- API REST de tareas con SQLite

## Ruta 3. Bibliotecas

Aprende en este orden:

1. diseño de APIs
2. tests
3. traits
4. genericos
5. benchmarks

Proyecto sugerido:

- libreria de parsing o formateo

## Ruta 4. Sistemas y rendimiento

Aprende en este orden:

1. ownership profundo
2. iteradores e I/O
3. concurrencia
4. profiling
5. unsafe solo mucho mas adelante

Proyecto sugerido:

- indexador de archivos o mini grep

## Objetivo de los proximos 30 dias

Despues de este curso, intenta cerrar al menos uno de estos objetivos:

- una CLI util
- una API pequena
- una libreria propia con tests
- un proyecto que lea y escriba JSON o CSV

## Indicador de progreso real

Estas creciendo bien si ya notas que:

- decides mejor tus firmas
- usas menos `unwrap()`
- casi no metes `clone()` por impulso
- diseñas mejores enums
- piensas antes de mutar
