# Soluciones Completas Ejecutables

Este documento enlaza las soluciones completas de los 30 retos en formato ejecutable. Cada reto vive como binario separado dentro de `src/bin/`.

## Como usarlas

Ejecuta un reto concreto con:

```bash
cargo run --bin nombre_del_reto
```

En retos con argumentos:

```bash
cargo run --bin reto_24_args_reales -- add tarea
cargo run --bin reto_30_cli_tareas -- list
```
